LUMIA WEB - EXECUTAVEL PARA WINDOWS

1. Extraia todos os arquivos deste pacote para uma pasta comum.
2. Abra LumIA-Web.exe com duplo clique.
3. O programa iniciara o servidor local e abrira o navegador automaticamente.
4. Para fechar o sistema, feche a janela do terminal ou pressione Ctrl+C.

DADOS
O arquivo lumia.db sera criado ao lado do executavel na primeira execucao.
Ele guarda atividades, respostas, notas e feedbacks. Nao apague esse arquivo
se quiser manter os dados. Faca uma copia de seguranca antes de substituir
o executavel por uma versao mais nova.

REQUISITOS
Windows 10 ou 11, 64 bits. Python nao precisa estar instalado.

O LumIA Web roda somente neste computador, em endereco local (127.0.0.1).
Este prototipo academico nao deve ser exposto diretamente a internet.
